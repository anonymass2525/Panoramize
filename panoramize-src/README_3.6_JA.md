# Panoramize 3.6 — 技術検証レポート（2026-10-31）

## 判定
研究用の**可変トポロジー・3D四面体FEM＋6弦連成物理コア**および**制約付き物理逆設計器**を実装。実ギター録音の材質・形状の完全復元は未達。新エンジンはVST3のGUIには未統合。

## 3.5からの主な変更
- `GeneralizedFEM36` は3.5の共通ブリッジ結合、横・縦・ねじり自由度、押弦・摩擦を継承した新しい独立C++ DSPエンジン。
- 3Dメッシュはテキストで指定。上限32頂点・96四面体、各弦のブリッジ結合頂点を個別指定。ゼロ体積・重複頂点・範囲外インデックス・遊離頂点を拒否。
- 小変形線形FEMに異方性: 6×6剛性 `D = S D_isotropic S` (S: 正値対角6成分の平方根)。したがってSPD/PSD。任意の完全異方性弾性テンソル、非線形木材損傷、繊維方向の局所回転には未対応。
- `MeshInverse36` は与えた複数メッシュ仮説から、弾弦位置・ブリッジ結合・ヤング率・弦張力・3成分異方性・x/y形状スケールの局所探索を実行。短いドライ録音の波形・時間窓エネルギーの加重誤差を評価。
- 未使用録音のデータは最適化と順位付けに使用しない。既知MIDI音高・ベロシティ・同期済み音頭を仮定。
- 従来の3.5専用エンジン、旧72音色、過去バージョンのパッチ実装は保持。

## 実測（Linux x86_64, 48kHz、2048サンプル、全6弦演奏）
- 8頂点・6四面体: 25.70ms／ブロック。
- 9頂点・7四面体: 26.22ms／ブロック。
- 実時間予算42.67ms。このベンチは単一プロセスでの実験条件、Windows/Studio One実測ではない。

## 合成既知モデルでの逆設計
入力: 22,050Hz、約52msの録音3例。2例学習、1例独立評価。42候補評価（メッシュ仮説ごとに予算配分）。

|順位|形状候補|学習誤差|未使用演奏誤差|
|---|---|---:|---:|
|1|9頂点・7四面体|0.0573995|0.3024835|
|2|8頂点・6四面体|0.0848612|0.5974355|

正解: 9頂点、ヤング率540MPa、弾弦位置0.72、ブリッジ結合0.095、異方性正規倍率 [1.3,0.65,1.8,...]。
推定最良: 9頂点、ヤング率450MPa、弾弦位置0.71、ブリッジ結合0.1024、異方性 [1.28,0.72,0.72,...]。
異方性z軸は大きく誤推定。材質・形状は互いの音響効果を補償できるため一意識別不能な場合がある。
重要: **正解のトポロジーをメッシュ候補集合に含めた**。未知形状を生成した実験ではない。

## 制限と次の課題
- 新しい3.6メッシュソルバーはCLI・C++ライブラリとして稼働。**旧JUCE GUIは3.5エンジンを使用し続ける**。新ノードへの配線とリアルタイムメッシュ編集は未実装。
- 適用可能な上限は32頂点・96四面体であり、精密なギター胴の大規模3D構造を表現できない。連成接触は3.5を引き継いだ近似モデル。アコースティックギター特有の放射・木材異方性・マイク配置は十分にモデル化していない。
- 逆設計は非常に短い開始時刻既知のドライ録音、弦のMIDI音高・ベロシティ既知に限定。異なる奏法の長時間録音、実録音、3D未知形状生成・全物理パラメータの識別は未検証。
- 3.6を将来Studio OneのGUIに繋ぐには、メッシュファイルのリアルタイム安全な準備、非音声スレッドでの行列組み立て、保存形式のバージョン管理、MIDI統合、Windows検証が必要。
