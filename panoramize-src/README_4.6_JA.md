# Panoramize 4.6.0 — Long-form Gesture & Generative Inverse Design (研究用CLI)

## 何を実装したか
v4.5までの音声合成・物理モデリングを変更せず、**オフライン逆設計**に新しい`deep46`モジュールを追加しました。リアルタイムのVST3プロセスとは分離されています。

1. **長時間の音色変化**: 最大30秒（8–96kHz）のドライ単音WAVを時間フレームに区切り、RMS、スペクトル重心、明るさ（1.5kHz以上のスペクトル重み）、スペクトル平坦度、推定ピッチと信頼度を保存。0.5秒単位の集計CSVも出力します。
2. **奏法候補**: 既存PerformancePhysical30のピッチ・エネルギーイベント推定を再利用し、ビブラートは推定音高の周期性から3–9Hzの候補を独立評価。レガートは大きな滑らかな音高移動で、アタックイベントを伴わない場合の「候補」に留める。表現の意図や実際の演奏法は音声だけでは確定できません。
3. **材質パラメーター探索**: 既存ShapeInverse37で生成した3D構造を起点に、FEM36のヤング率、密度、異方性、弦の励振位置、ブリッジ剛性を有界探索。パラメーターは実物材質に校正された値とは限りません。
4. **形状設計**: 3Dの格子分割、外形寸法、反り、テーパーをパラメーターで生成し、その候補を物理レンダリングして比較。無制約な未知CAD形状の再構築ではありません。
5. **励振位置推定**: 1D弦・2D膜の限定生成モデルについて既知のピックアップ位置を条件とし、候補励振位置・基本振動数・格子分割・減衰を比較。FEM36の弦の励振位置も探索。未知のマイク位置と未知の弾弦位置を同時に特定することはできません。

### 操作方法
```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure -E '^PANORAMA_DSP$'

# 各機能が動く人工音声の一式
./build/panoramize_deep46 --demo demo46

# 実WAVの長時間解析（8–96 kHz PCM16/24/float32、monoまたはstereo）
./build/panoramize_deep46 --analyze my_dry_monophonic.wav analysis_output

# 弦/膜の位置推定（訓練・検証は別WAV、同一開始時刻とサンプルレート）
./build/panoramize_deep46 --fit-wave string train.wav holdout.wav output_string 0.64 48
./build/panoramize_deep46 --fit-wave membrane train.wav holdout.wav output_membrane 0.64 48

# 3D FEMの形状・物性候補探索。manifestは train|file.wav|midi|velocity 形式
./build/panoramize_deep46 --fit-fem fem_recordings.txt fem_output 64
```

### データの制約
* 解析は**単音のドライWAV**が主対象。PCM16/24、float32、モノ／ステレオを読めますが、ステレオは平均してモノへ変換します。発音開始がずれた録音や残響音が混じった録音では解析誤差が増える場合があります。
* 長時間の音色・奏法解析は8–96kHz、約0.33～30秒。FFT=1024サンプル、ホップ=256（必要に応じ512）。30秒データをすべて読み込むためオフラインです。
* 物理逆設計は限定的な短い録音（2,048サンプル以上、最大2秒）を扱う。長時間WAVを直接FEMで30秒フィットする統合最適化ではありません。
* 弦・膜の探索は先に列挙した格子寸法と励振位置の有限候補で、既知ピックアップ・既知物理ファミリーが前提。構造や励振の対称性により同程度の候補が複数出る場合があります。
* 3D形状の候補は矩形格子から生成する限られた四面体構造。未知形状の一意な復元や完全な材質特定はできません。
* ホールドアウト録音はパラメータ選択に使わず、選択後に評価します。上位候補の誤差差が小さい場合は識別不確かとみなします。
* 音響的距離は音量・FFT重心・明るさ・平坦度と、位相が既知の人工実験に補助的な波形コヒーレンスを混ぜたもの。心理音響的な音質評価ではなく、スコアが低くても材質や形状の真値を意味しません。

### テスト（Linux）
* Release: `PANORAMA_DSP`（従来から時間がかかる旧テスト）を除いた **39/39件合格**。
* 新モジュールの集中したASan/UBSanスモークテスト合格。長時間のASan/UBSan統合テストは実行時間制限により未完了。
* 8秒の人工的レガート／ビブラート／音色変化を分析。1D弦と2D膜の合成既知位置0.28を、48候補評価でともに最良に選択。
* 3D物理は生成形状の複数候補を保存し、未使用音高での評価を出力。正解トポロジーや密度は一意には復元できていません。
* Windows VST3 / pluginval / Studio One実機は今回未検証。4.6新機能はオフラインCLIのみで、JUCEの新しいGUI編集機能としては未統合。
