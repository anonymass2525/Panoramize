# Panoramize 4.1 — Energy-Consistent Spatial Boundary Ports

## 今回の実装範囲

- 実際の空間変位自由度を備えた1D弦（12節点）、2D膜（3×3節点）、3D四面体FEM（8頂点・6四面体）と、SIに校正した0D音響空洞（体積変位[m³]、体積速度[m³/s]）を一つの物理状態ベクトルに集約。
- すべての領域を一つの連立行列による**同時の陰的中点法**で積分。内部連成を前サンプルへ遅延させない。自由度は合計46。
- 境界は節点の重み付きポート: `x_b = ∑w_i q_i`, `v_b = ∑w_i v_i`。反力を重みの転置で節点へ配るので、境界の力×速度と格子へ注入される仕事率が対応する。
- 弦↔膜、膜↔3D共鳴体はN/mの保存ばね、N·s/mの散逸ダンパー。
- 3D共鳴体↔音響空洞は有効面積 `A [m²]` で `ΔV=A*x_b-q_cavity` とし、`K [Pa/m³]`,`D [Pa·s/m³]` の保存・散逸結合。機械へ加える反力は `A×p`、流体へ加える圧力は逆向きで整合。
- `Ledger`: 初期エネルギー、外部能動仕事、散逸、最終エネルギー、収支残差。線形一定係数・二次エネルギーの演算に対する検証。
- 従来の8種類の `native27` 音響状態（VA/FM/スペクトル/位相/共鳴/物理/発声/非線形）はオプションとして接続可能。ただし正規化状態とSIの対応は未校正のため、**能動・1サンプル遅延の接続**と明示し、仕事量は別計上。受動性は主張しない。
- `.boundary41` 独立保存形式と、Universal Patchbayの `.pgraph` 新 `BoundaryGraph41` ノードを実装。既存の3.9/4.0コードと音色は残置。

## 動作方法 (Linux)

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure
./build/panoramize_boundary41_demo ./boundary
./build/panoramize_boundary41_benchmark
```

出力: `boundary_coupled.wav`、`boundary_disconnected.wav`、`boundary_active_native.wav`、`boundary.boundary41`、`boundary.pgraph`。

## 限界

- 今回の3D連成は **8頂点の線形・等方性四面体弾性FEM**。3.6の異方性材質を新しい一括陰的コアに統合したわけではない。最大12頂点のボディ、3〜4点角の膜など、小規模な研究用モデルに限定。
- 全ての固体を粘弾性・大変形・摩擦接触まで解く方式ではない。弦・膜の方程式も簡略化。
- 4.0の既存 `EnergyPorts40` は独立して残り、完全な多任意グラフ（任意個数・任意構造の1D/2D/3Dオブジェクト）への統合は未達。
- 3D/空気の境界は線形化したコンプライアンスとダンパーであり、現実の放射インピーダンス・音響波の分布伝播は未モデル化。`native27` は明示的能動変換で、機械⇄既存全音響状態の厳密な受動解法ではない。
- GUIの既存Patchbayには新ソースの選択肢を追加したが、4.1境界形状をドラッグで編集する専用JUCE GUIは未実装。テキスト形式の編集と再読み込みに対応。
- 4.1はモデルを作り直さずにMIDI noteOnを行えるが、4.1専用のリアルタイムSI係数変更・行列再因子化機能は未実装。
- Windows VST3、JUCEエディタ、pluginval、Studio Oneは実機未検証。

## 後続計画

1. 一般的な四面体メッシュに対する疎行列陰的ソルバー（行列の増大を回避）。
2. 境界接触の非線形・移動条件と受動性を確保した拘束解法。
3. 音響側の物理量を定義できないスペクトル・非線形・発声モードには、能動ポートの仕事・エネルギー補給量と安全制限をより厳密に適用する。
4. グラフ編集GUIとオーディオ無停止の構造更新を実機で検証。
