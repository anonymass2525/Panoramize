# Panoramize 4.2 — Sparse Port-Hamiltonian Research Graph

**4.1の46変位自由度の固定・密行列モデルをそのまま残し、任意のメッシュ・領域を組み立てられる疎行列研究DSP `sparse42` を新設。**

## 追加したモデル
- **1D String:** 頂点座標と任意の線分集合から、張力と線密度を使った有限要素の質量・剛性を組み立てる。横変位1自由度/節点。
- **2D Membrane:** 空間内に置いた任意の三角形網で、面密度・膜張力・三角形の形状関数勾配による2D FEM。節点の面外変位1自由度。**薄板の曲げFEMではない**。
- **3D Elastic:** 任意の4頂点四面体メッシュから小変形等方性線形弾性 `K_e=∫BᵀCB dV`、集中質量。x/y/zの3自由度/頂点。木材の真の異方性、非線形接触、大変形は未実装。
- **0D Acoustic:** 容積に基づく集中音響空洞モデル、体積変位Q[m³]・体積流量U[m³/s]と圧力p[Pa]。**1D/2D/3D空気場の分布波動FEMや放射境界ではない**。

複数インスタンスの1D/2D/3D構造を、独立にメッシュ頂点・要素で定義して追加できる。研究用安全上限は48領域、4096変位自由度、256ポート、512リンク、領域最大2048頂点。無制限ではない。

## ハミルトン構造と境界ポート
一般化座標qと運動量p=Mvから、

    H = (1/2) pᵀ M⁻¹ p + (1/2) qᵀ K q
    [q̇; ṗ] = ([0 I; −I 0] − [0 0; 0 D]) [∇qH; ∇pH] + [0; B] u

と定義する。離散されたMは正の対角（集中質量）、Kは対称半正定値の空間FEM＋保存リンク、Dは非負の損失行列。能動励振uは独立仕事計に記録。

境界ポートはノード変位の**重み付き線形補間** `ξ = C q`。転置の `Cᵀ` で反作用の力を分配。物理領域から音響領域へは指定面積A[m²]を掛けて `ΔV = A ξ_mechanical − Q_acoustic` へ変換する。これは同じ離散一般化エネルギー上の仕事共役関係であり、旧3.9の単位未校正Nativeアダプターとは違う。

保存リンクのポテンシャルエネルギーは `k(Δξ)²/2`、損失リンクは `d(Δξ̇)² ≥ 0`。接続先の自由度は任意節点に配置でき、0D音響ポートと3D FEM面を結合できる。ただし接続パッチ面積の実物形状校正はユーザー側が行う。

## 疎行列・同時陰解法
- FEM局所要素とリンクを準備時に対称Triplet形式で足し込み、`K`,`D`,`A` をCSR疎行列へ変換。
- 陰的中点法で、**同時連成方程式** `(2M/h+D+hK/2)v_mid=(2M/h)v_n−K q_n+Bu` を解く。
- 4.1の密Choleskyの代わりに、**対角前処理付き共役勾配法（PCG）**を採用。前サンプルの中点速度を初期値として再利用。
- 演算時に新しいメッシュ、CSR構造、作業ベクトルを確保しない。最大反復回数と許容相対残差をレシピに記録。**収束できない場合は安全側でそのサンプルの状態更新を拒否しゼロ音声を出す**（ドロップが発生し得る）。
- 行列構造は固定。演奏中の追加・削除・材質変更をリアルタイム無停止で行う仕組みや自動再前処理は未実装。パッチの準備は音声処理外で実行。

## 使い方

    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
    cmake --build build --target panoramize_sparse42_demo panoramize_sparse42_test -j4
    build/panoramize_sparse42_test
    build/panoramize_sparse42_demo --example example.sparse42
    build/panoramize_sparse42_demo example.sparse42 output.wav 1.0 48000
    build/panoramize_sparse42_benchmark

`.sparse42`はテキスト形式。`REG`で領域種類と物性、`V`で任意3D座標、`E`で線分／三角形／四面体、`P`で領域内の重み付き境界ポート、`L`で保存ばね・ダンパー・面積変換を記録。`.pgraph`に`SPARSE42_BEGIN / END`で埋め込むと、既存Universal Patchbayの`SparseHamiltonian42`ソースからMIDIで鳴らせる（Linux C++テストで確認）。ファイルの読み書きでは無効な単位・節点・パラメータを拒否。

## 何が未達か
- 真の任意3D形状の大規模高速実用処理、周波数に依存する減衰、異方性材料、接触、非線形変形、1D/2D/3D空間空気場はまだ未実装。
- 4.2は既存のNativeState27 / UnifiedAcousticStateGraphの全モードを物理的受動ポートへ**統合完了していない**。旧4.1の能動Nativeブリッジは残るが、4.2には接続していない。
- 汎用境界ポートの自動メッシュ面抽出、FEM制約条件のGUI編集、マルチレート、非線形陰解法や完全な安定証明、複数同時ボイスの独立空間グラフは未達。
- Universal Patchbayのノード種選択まではソースを追加したが、**メッシュ/ポートを編集する専用JUCE GUIは未実装**。Windows VST3/JUCE/pluginval/Studio Oneは未検証。
- CTest全35件のうち既存`PANORAMA_DSP`は長時間実行となり12秒で打切った。ほか**34/34合格**。Sanitizerは新コア単独テスト合格。
