# Panoramize v3.7.0 — Generative Physical Structure (研究版)

## 研究目的
3.6の「録音から既存のメッシュ候補を順位付けする」方式から、**数理パラメータから四面体メッシュを生成し、形状と物性を交互に変形・最適化する**方式へ進めたもの。これとは別に、弦(1D)、膜(2D)、板(2D)、管(1D)を扱う演算子を共通の `WaveRecipe` APIへ追加した。

### 実装した機能
- `gen37::Shape`: x/y/zの分割数、長さ・幅・厚さ・反り・テーパーを持つ。上限は3.6のFEM36由来の32頂点／96四面体。
- `buildTetraMesh`: 六面体を6個の四面体へ分割。連結・非退化条件を検査し、6本の弦の接続点を自動配置。
- `gen37::discover`: 初期に**ユーザーから正解メッシュ候補を渡さず**、最大11種類の格子トポロジーを自動生成して粗探索、最良の複数候補に限り形状(寸法・反り・テーパー)と物理パラメータ(ヤング率、ブリッジ結合、弾弦位置、異方性倍率)を局所探索。学習・未使用録音を厳密に分離。
- `.wave37`: 弦・膜・板・管のレシピを保存・再読み込みして同じWAVを再生成可能。
- `renderWave`: 弦は1Dの張力波、膜は2D張力波、板は2D双調和項による曲げ正則化、管は1D音圧／流速の差分更新。各方程式を無理に同じものと見なさない。共通形式で呼び出す限定的な汎用基盤。
- 3Dは3.6の弦と四面体FEMの連成を使用。`--demo`で入力WAV、推定レシピ、再合成、4種類の波動サンプルを作成できる。

### ビルド・使い方
```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure
./build/panoramize_render37 --demo demo37
./build/panoramize_render37 demo37/recordings.txt demo37/my_inference 70
./build/panoramize_render37 --wave demo37/wave_tube.wave37 demo37/tube_reloaded.wav
```

`recordings.txt`は`train|file.wav|midi|velocity` または `holdout|file.wav|midi|velocity`。同期したドライ単音WAV（PCM16/24、float32、22.05〜96kHz、各256サンプル〜2秒）。共通のサンプルレートで、音高とベロシティは現時点ではユーザーから与える。学習に未使用録音は使わない。

探索の出力は `.shape37`、FEM36互換の`.mesh36`、`.fem36`と、各録音に対応するWAV・ランキングCSV。`.fem36`は3.6の実験用ソルバーへ読み込ませることができる。

### 重要な制限
- 入力した真の3D形状の完全復元は不可能。候補生成の探索空間は矩形格子を基とする反り・テーパー・寸法変更に限定。自由な任意CADメッシュや自動リメッシュの一般解ではない。
- 3Dソルバーは小変形線形FEM・制限された異方性弾性。リアルな木材繊維・空気放射・指との複雑な摩擦モデルは未完成。
- 弦・膜・板・管の4方式はそれぞれ**独立した研究用簡略差分ソルバー**であり、4方式同士、あるいはFEM36との双方向物理結合はまだ未実装。メッシュ逆設計に使うのは現時点では3D FEM36のみ。
- 2D板は単純な曲げ項、管は1Dの無次元音響管。実物楽器の校正済み物理モデルではない。
- 現実の録音での逆推定精度、長時間奏法、未知の管/膜/板の逆設計、任意の3D形状自動生成は未検証。
- 3.7新コアは現在CLI/C++研究機能。**3.7用の新GUI編集ノードおよびWindows Studio Oneでの動作は未実装／未検証**。既存VST3コードは旧発音機能を保持。
- 計算予算と入力制約のため結果は局所解。単音録音から物理物性を一意に求められない。
