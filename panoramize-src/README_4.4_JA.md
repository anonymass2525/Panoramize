# Panoramize 4.4.0 — Structure-Preserving Model Reduction / Multirate Boundary Schur

## 4.3からの変更

**4.3の疎行列／IC(0)エンジンを保持したまま**、新しい`reduced44` C++17音源を追加。1D弦・2D膜・3D四面体弾性体・音響管・空洞・共鳴／スペクトル近似モードの既存4.3演算子を再利用する。

### 1. 境界自由度を残した構造保存型縮約
- 4.3が組み立てる質量M（集中質量）、剛性K、減衰R、境界ポートCを**オフライン準備時**に読み出す（`SparseHamiltonian43::Instrument::exportAssembled()`）。
- ポートが参照する全自由度を**境界自由度として恒等保持**。外部ポート入力と出力の線形写像は縮約空間でも保つ。
- 内部変形は**Craig–Bampton型の静的拘束モード**と、固定境界剛性問題の低周波モードを**逆反復で近似**した基底で表現。剛性の特異性を避けるため1Hz相当の質量正則化を使用。完全な精密固有値解析ではない。
- `q=Tq_r`、`M_r=T^T M T`、`K_r=T^T K T`、`R_r=T^T R T`（質量は**非対角**も保持）。元の非負剛性・非負減衰・正の質量から縮約後の受動性を維持する。ただし形状・倍音は**近似**。

### 2. 境界保持の領域分割＋Schur補
- 1D/2D/3D・音響領域ごとに内部演算器を分割し、ポートに跨るリンクは**まとめて境界Schur補**で計算する。
- 力の戻り経路は常にポート変換行列の転置 `C^T`。結合ばね・ダンパーは作用反作用で同一エネルギーを共有。
- 4.3の全領域CSR-PCGを残したまま、4.4の小さい**領域ブロックCholesky／Schur補**を追加。Schur補の小行列は準備時にピボット付き消去で逆行列を作成。
- 物理レシピは`.reduced44`、PanoramizeのMIDI音源は`Kind=22`、`.pgraph`ヘッダーは`PANORAMIZE-GRAPH-44|1`。

### 3. マルチレートの受動性を保つ境界接続
- 領域ごとに`rateFactor=1,2,4`を指定。準備時に各領域の陰的中点法をその時間分割で繰り返し、入力力に対する**状態遷移と応答行列**を前計算。
- 実行時に境界Schur補を同じサンプル内で一度解き、全領域の反力と終端状態を**同時に決定**する。旧式の陽的/単純なStrang分割による不安定化は使用しない。
- ばねのインターフェース力は平均変位、ダンパーは**1サンプル区間の境界変位差**から作り、サンプル単位の保存・散逸のエネルギー交換を整合させる。
- 減衰量は、領域内各サブステップの速度とRから準備時に作った正半定値二次形式を使用して**独立に積算**する。エネルギー差の帳尻合わせではない。
- 系が**線形・時不変**である範囲で前計算可能。時変メッシュ、接触／摩擦の非線形、GUIのライブトポロジー編集を高速化できたわけではない。

## ビルドと操作
```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build -E '^PANORAMA_DSP$' --output-on-failure
build/panoramize_reduced44_demo --write-example example.reduced44
build/panoramize_reduced44_demo --write-large large.reduced44
build/panoramize_reduced44_demo example.reduced44 example.wav 1.2 48000
build/panoramize_reduced44_benchmark
```

`rateFactor`、`modesPerRegion`、音響ゲイン／材質／領域は`.reduced44`テキストで変更可能。毎回再準備する構造であり、音声処理中にトポロジーを変更するインターフェースは現時点で未対応。

## 実測の目安（2026-10-31、Linux、48kHz／64フレーム）
- 72自由度 → 36自由度、7境界自由度保存、224非ゼロ係数。
- 451自由度 → 50自由度、9境界自由度保存、326非ゼロ係数。
- **451自由度**の旧4.3＝1360µs、4.4単一レート＝369µs、4.4マルチレート＝**232µs**（CPUブロック時間中央値）。実時間予算約1333µs。
- **72自由度**の旧4.3＝174µs、4.4単一レート＝225µs、4.4マルチレート＝**164µs**。小型モデルでは縮約の前処理や行列演算がオーバーヘッドになる。
- 大型モデルの旧4.3と4.4比較音声の波形相関は約0.99909、波形相対L2誤差は約4.27%。**ビット一致／完全等音質ではない**。
- `CTest -E '^PANORAMA_DSP$'`: 36/36合格、Clang ASan/UBSanの4.4専用テスト合格。高コスト旧`PANORAMA_DSP`テストは本実行では未実施。

## 明確な未達
- 最大自由度の上限と全サンプルレートでのリアルタイム性能・多重インスタンスを保証しない。オフライン前計算に元のFEMの準備費用と**領域内の密Cholesky（O(n³)）**、境界のSchur補行列逆行列を要する。
- 任意の非線形波動、スティックスリップ接触、木材異方性、完全FEM幾何再構成、全Native27非線形DSPのパッシブな組み込みは未実装。
- 追加したUniversal Patchbayの新ノードはテキストパッチから選択可能だが、詳細なポート・縮約モード・マルチレート比の専用GUIは未実装。Windows VST3、pluginval、Studio One実機は未検証。
- 今回は構造保存型**線形射影**であり、全音色を感覚的に同等と保証しない。音源ごとに音声差とCPUの両方を評価する必要がある。
