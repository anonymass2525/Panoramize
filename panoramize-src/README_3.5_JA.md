# Panoramize 3.5.0 — Six-String Coupled Physical Instrument

## 変更の核心

3.4は1本の空間離散化弦と3軸の低次元共鳴体。3.5は独立した6本の空間離散化弦を、同じ線形3D四面体メッシュへ**同一サブステップで力学的に結合**する新しい発音経路を追加した。

- 標準開放弦: E2（MIDI 40）、A2（45）、D3（50）、G3（55）、B3（59）、E4（64）。
- 1弦あたり24空間格子点、横変位・軸方向（縦）変位・ねじれ角をそれぞれ時間積分。6弦合計432変位自由度と対応する速度。
- 8頂点・6四面体の等方線形弾性メッシュ。各頂点にx/y/z自由度を持つため合計24変位自由度。形状関数・線形ひずみ・フック則に基づくFEM剛性行列を音声処理開始前に組み立てる。
- 各弦末端とメッシュの6接続点で、横・軸方向およびてこ腕を通したねじり方向の**作用反作用**を同じ時間積分の中で処理。ブリッジ結合率は0〜0.5で変更できる。
- 弦の非線形幾何学的伸び（小変位近似）、指の位置拘束、指板の片側ペナルティ接触、接触時の正則化された速度依存摩擦（滑り）、パームミュートの位置依存損失。
- MIDIコード演奏、ピッチベンド、圧力、サステイン、演奏操作CC20/22。`.pgraph`の保存・読込、Universal Patchbayの`SIX STRING FEM / 3.5`発音ソースと編集画面。
- 3.4以前のDSP・72ファクトリープリセットは保護して残す。3.5の新識別子は`Pz35`。新規ソースに限定して機能を追加。

## 物理モデルの限界

これは**現実のギターを計測・較正した完全なモデルではない**。四面体は6個のみで、線形・小変形の簡単な共鳴胴、張力・軸剛性・ねじり剛性は実効的な調整量。木材の繊維方向や実構造、正確な指／指板の接触形状、静止摩擦・スティックスリップ、ボディーの大変形、電磁ピックアップ、放射音響はまだない。特に接触は正則化摩擦＋ペナルティ法であり、厳密な非貫通拘束ではない。

弦を単にPCMで混ぜるのではなく、相互作用エネルギーを介した結合は実在する。しかし、上記条件の近似を超えて物理的精度を主張できない。

## ビルド・検証

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure
./build/panoramize_coupled35_demo coupled.wav coupled.pgraph coupled
./build/panoramize_coupled35_demo dry.wav dry.pgraph dry
./build/panoramize_coupled35_benchmark
```

Windowsビルドは同梱の`.github/workflows/windows-vst3.yml`から実施できる設定だが、**Windows x64でのコンパイル・pluginval・Studio One実機を今回は実行していない**。結果の成功を保証しない。

`CoupledEditor35.h`は15の実効物理パラメーターを編集可能。パラメーター変更はUIスレッドでグラフを再構築する設計なので、録音中の自動化と無音・瞬断の品質は追加検証が必要。
