- `include/GraphInverse.h` に複数案のAPI `inferGraphPortfolioFromAudioEx` を追加。
- `src/GraphInverse.cpp` に出力到達性ベースの構造署名・構造距離・最大256トポロジーの候補アーカイブ・誤差制約付き多様性選択を実装。

- DSP合成器本体・72プリセットを変更せず。独立VST3 ID `Pn19`。

## Linux実測
- CMake C++17 Release + Ninjaビルド成功、CTest 6/6合格。
- Clang ASan / UBSan 下のGraphInverseテスト成功。
- 入力は1.8で使用したKinetic LedgerのWAV（48kHz / MIDI 60）。
- 320候補を実評価し、最終出力につながる可聴グラフ署名で141種類を確認（1.8の未使用ノード込み172種類とは定義が違う）。
- 最良案のノード・パラメータは1.8の保存された最良JSONと一致。

## 同一入力音への4案の結果
- 第1案: 特徴量距離 0.05797720、構造距離 0.000000、出力到達ノード 5 個。
- 第2案: 特徴量距離 0.08026500、構造距離 0.714286、出力到達ノード 5 個。
- 第3案: 特徴量距離 0.08686780、構造距離 0.722222、出力到達ノード 1 個。
- 第4案: 特徴量距離 0.08881840、構造距離 0.714286、出力到達ノード 3 個。


距離は低域中心のスペクトル特徴＋3区間の相対的な音量変化を用いた値であり、聴感上の類似率ではない。比較MP3はRMS基準で音量を合わせた。元の推定パッチの絶対出力音量が一致したという意味ではない。
