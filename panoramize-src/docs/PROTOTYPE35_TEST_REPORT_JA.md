# Panoramize 3.5.0 — 六弦／3Dメッシュ連成物理楽器：検証レポート

## 結論

**6本の空間離散化した弦・ブリッジ結合・3D四面体共鳴体を1つの時間発展計算でつなぐ試作DSPを実装。** 前版3.4の1弦＋3軸共鳴体から前進した。現実のギターの完全物理解析モデルではない。

## 実装の内容

- 開放弦6本（MIDI 40,45,50,55,59,64）。各弦24空間格子×横／縦／ねじれ3自由度 = **432変位DOF**。各DOFに速度を別途保持。
- 共鳴体は**8頂点・6四面体・24変位DOF**。3次元線形弾性FEM（B^T D B、密度で質量行列の対角成分を組立て）。剛体移動を抑える固定端近似を含む。したがって **全456変位DOF**（および456速度）の系。
- 6弦の各末端を6つのメッシュ接続頂点に接続し、作用反作用を同一のサブステップに入れた。横変位・縦変位・ねじれを結合。ねじりのメッシュ伝達は実効的てこ腕を使う。
- 弦振動は幾何学的伸びの小変位近似。指板衝突は片側ペナルティばね・減衰、摩擦は正則化したCoulomb風速度依存滑り摩擦（軸方向・ねじれ方向）。パームミュートは位置依存損失。実指の3D接触、静止摩擦、スティックスリップ、非線形木材挙動は未実装。
- 非線形的接触とばね・FEM力を含む力積を、明示的サブステップ付き速度Verletで時間積分。グラフ`Kind::PhysicalCoupled35`としてUniversal Patchbayへ追加。
- `.pgraph`のテキスト保存・読み込みに対応。`PANORAMIZE-GRAPH-35|1`、旧34以前の保存フォーマットは維持。JUCEに新発音ソース選択と15パラメーター編集画面を追加（Windows GUI表示は未検証）。VST3識別子`Pz35`。

## Linux動作検証

- Release CMake/Ninjaビルド: 成功。
- **CTest 24/24合格**（既存23 + 新1）。
- 新コアに対するClang ASan/UBSan: 合格。
- 1弦だけを励振し、共鳴胴および未励振5弦の機械エネルギーが正となることを検証。ブリッジ結合を0にすると共鳴胴へのエネルギー伝達が消える。
- 指板への侵入検出が有限回発生、縦振動・ねじれ振動も非ゼロ、サンプルは有限。6本同時ノートのMIDI検証・保存往復・Universal Patchbay経由の音声発生を確認。
- 減衰／摩擦なし・サステインを保持した孤立系の**1秒後の機械エネルギー比 0.999964**（実行環境の浮動小数点結果）。全条件で厳密な保存を保証するものではない。

## CPU測定

48kHz / 2048フレーム（1ブロックの実時間予算約42.67ms）、Linux Release、6弦楽器を複数インスタンス実行。

```text
1 x six-string instruments: 29.0941 ms / 2048 @48kHz, budget 42.67 ms
2 x six-string instruments: 54.9802 ms / 2048 @48kHz, budget 42.67 ms
4 x six-string instruments: 101.444 ms / 2048 @48kHz, budget 42.67 ms
8 x six-string instruments: 203.9 ms / 2048 @48kHz, budget 42.67 ms
```

**1インスタンスは予算内、2インスタンス以上は今回の環境では超過。** 実機のStudio OneのCPU性能・オーディオバッファ設定を保証しない。音質と物理状態の自由度を優先し、実時間処理の最適化は必要。

## オーディオ証拠

`Panoramize_v3.5.0_Audio_and_Patches.zip`には48kHz・24bitモノWAV4種：coupled（連成有り）、dry（ブリッジ結合なし）、palm（途中から掌を当てる）、slide（スライド遷移）と設定`.pgraph`、演奏イベントCSV、音響RMS値、MP3を同梱。単純な聴感差と機構試験を分けて解釈すること。

## 未達・留保

- 実際のギターから幾何形状・材質・弦張力を同定した実測モデルではない。
- 共鳴胴を線形小変形の**6四面体**で近似。現実の木材異方性、大変形、表面放射・空気結合、実際の複雑なブリッジ構造と縦・ねじれの分布を再現するにはFEM要素数・材質・放射モデルを増やす必要がある。
- 真のスティックスリップ／静止摩擦・完全非貫通制約は未実装。
- コード実装済みのJUCE UIについて、**Windows VST3ビルド／pluginval／Studio One実機試験は未実施**。エディター操作中はDSP再構築を伴うため、演奏中のパラメーター自動化は要検証。
- 今回は3.1逆合成器への3.5高精度モデルの組み込みや、実録音からの3D形状自動最適化は未達。

## 今後の重点

- リアルタイム負荷削減（疎行列化、弦／ボディの分離時間スケール・受動性を守るモデル縮約、複数インスタンス処理）。
- もっと現実的な6弦ブリッジ形状、異方性材質、弦の曲げ・ねじり・軸方向の物理的パラメーター化、ストリング／フレット接触の補完条件型解法。
- 3.1 Joint Inverseへ空間格子系を探索モデルとして接続して、演奏条件と楽器構造を同時推定。
- Windows実機合格後、Studio OneでRealtime/Offlineサンプル一致や音切れ、パッチ復元などを再検証。
