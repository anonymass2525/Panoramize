## 具体的な未完項目

統一アーキテクチャへ完全移植したという主張はできない。現実に実装したのは、旧72プリセットを独立した「Legacy Source」音声ソースとして統一可変グラフへ取り込むBridge。旧モジュラー24ノード個々の内部音響状態を直接相互交換するわけではない。GUIは最大64ノードの編集に対応するが、接続はまだ音声A/Bと新統一ソルバーの内蔵6モードに制約される。一般化されたport-Hamiltonian接続や真の物理的意味を持つエネルギー変換は将来実装が必要。
