# Panoramize Prototype 4.5.0 — 非線形接触・FEM・Native系受動代理モデル 検証レポート

2026年10月31日 / Linux C++17 Release

## 判定
**限定的な研究実装に成功。** 1D・2D・3D空間FEMとNative27系の8モードを、正の質量・剛性・散逸で構成する代理振動系として疎行列連成し、受動接触・有限伸び・正則化摩擦・能動励振を区分できる。

**未達:** ユーザーの指定する「既存Native27の任意の非線形・発声・スペクトルDSPをすべてそのまま受動化」は実現していない。VA/FM発振等は外部エネルギーを要求し、任意の処理が受動とは限らない。4.5で用いるのはNative27のEngine種別・モードパラメータとエッジに対応する**エネルギー正規化振動代理モデル**。本来の位相処理、子音生成、声道共鳴フィルター、スペクトル変形アルゴリズムをこの新DSPで完全実行する実装ではない。

## 追加ソース
- `include/NonlinearPassive45.h` / `src/NonlinearPassive45.cpp`: 3D変形辺、摩擦、離散勾配接触、Native代理モード結合、原理的受動性・能動性の分類、エネルギー収支、CSR-PCG。
- `tests/test_passive45.cpp`: 試作80自由度の発音、エネルギー収支、接触実動作と接触なし比較、3D頂点変位、保存/復元、型・値・不正ポート拒否、厳格受動モード、Universal Patchbayと旧4.4の互換。
- `tools/render_passive45.cpp`: `.passive45`または`.pgraph`を48kHz float WAVにレンダリング。
- `tools/benchmark_passive45.cpp`: 単体64フレームベンチマーク。
- `examples/passive45/`: 4条件の編集可能なモデル/Universalパッチ。

## テスト
- Linux Release全体ビルド成功。
- 旧長時間テスト`PANORAMA_DSP`を除いた **CTest 37/37件合格**。
- Clang ASan/UBSan、4.5の新規専用テスト合格。
- 80自由度（旧空間FEMとNative系8モード）の2,000サンプル: **非線形反復失敗0、接触検出1,235回**。エネルギー収支: 最終0.954621J、累積能動仕事1.10708J、累積散逸0.152458J、残差約−1.14e-14J。
- 接触/有限伸びあり・なしの1,300サンプル二乗波形差合計約0.00856419。
- 3D変形メッシュ頂点位置を読み出し、初期位置からの移動を確認。
- 厳格受動設定で、Native27の元モデルの非零励振を拒否。励振0の代理モードは受動連成として実行可能。
- Universal Patchbayの`Kind::NonlinearPassive45=23`パッチ往復・MIDI発音、4.4パッチの往復を確認。

**4.5は低レイテンシの実用段階に達していない。** 4.4の高速な線形縮約モデルに非線形接触処理を効率的に組み込む最適化は今後の課題。

## 残課題
1. Native27のすべての元のアルゴリズム（発声・FM/VA・位相・非線形・スペクトル）をそのまま共通受動ポートへ変換することは未達。自動的に受動化できないものは、エネルギー供給・出力を計量できる能動境界へ分類する必要がある。
2. 厳密な静止摩擦/衝突補完性、幾何学的完全非線形3D FEM、変形後の再メッシュ、音響放射・身体接触は未実装。
3. 接触での強剛性・大入力条件には反復解法の不収束があり得る。その際は状態の更新を中断・失敗件数を積算して安全側に停止する。
4. 新4.5はWindows VST3/GUI専用エディタ/pluginval/Studio One実機では未検証。Universal Patchbayでの種別選択のC++コードは追加済みだが4.5の専用3Dビジュアル編集は未実装。
