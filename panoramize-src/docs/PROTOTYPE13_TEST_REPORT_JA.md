# PANORAMA typeGPT Prototype 1.3.0 — 技術検証レポート

## 研究テーマ

- 全グラフを検証したうえで出力から到達可能なノードと有効なオーディオレートModRoute依存だけを実行する。
- Resonant Exchangeの4共鳴モードの係数と交換角について、同じ入力なら同じsin/cosを再利用する。
- 古い音色を近似せず、旧1.2と同一のサンプル値を保持する。

## CPUベンチマーク（参考値）

Linuxの仮想実行環境、非固定CPU割当。GCC -O3、48kHz、2,400フレーム＝実時間50ms相当、16音同時。各ケース3回の中央値を採用。結果は機材・負荷で変動し、Studio Oneでのリアルタイム保証にはならない。

| プリセット | 1.2 (ms) | 1.3 (ms) |
|---|---:|---:|
| 37 Resonant Loom | 68.6 | 40.2 |
| 38 Amber Tides | 82.1 | 40.9 |
| 39 Ferroflora | 85.2 | 49.4 |
| 40 Aurora Reciprocity | 94.8 | 38.1 |
| 56 Continuum Organ | 241.8 | 101.5 |

なお、別々の実行タイミングでの測定のためCPU負荷変動の影響を受ける。同じ条件で改善が示唆されたが、具体的な高速化率を一般化しない。16音同時の50ms予算を超えるプリセットは残る。

**カスタムグラフの到達可能性検証**: VA→Outputの有効な2ノードのみ使用し、他にSpectralMatter、FormantField、MatterWeave、ResonantExchangeを未使用配置した16音・2,400フレームの5回中央値は、1.2が80.7ms、1.3が20.3ms。これは未使用ノードが多い意図的な試験ケースであり、ファクトリープリセット全体の改善率ではない。

## 互換性と限界

- 56プリセットの数・定義・原音は変更していない。音質改善のための合成方式追加ではなく、演算最適化の研究版。
- 1.3はVST3識別子`Pn13`を使用。旧版と同時インストールする設計だが、Windows/Studio Oneでの認識は未確認。
- 出力に寄与しなかったノードをノートの途中で新たに接続すると、以前の版と内部状態の履歴が異なる可能性がある。接続変更時の音のつながりは実機で確認する必要がある。
- 固定Color、ピッチの係数キャッシュは、変化時に元の三角関数を再評価する。近似波形を用いていない。
- 音質、エイリアシング、16音のリアルタイム余裕、DAW保存・オートメーション・複数インスタンスの完全性については継続検証する。

**判定：Linux DSP・音声一致・ASan/UBSan合格。WindowsとStudio Oneの実機検証待ち。**
