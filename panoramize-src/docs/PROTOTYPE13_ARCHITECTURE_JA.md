# Prototype 1.3 — 音響グラフ到達可能性と共鳴係数キャッシュ

## 実行ノードの抽出

`compileGraph` / `validateModRoutes` は従来どおり全9ノードを検査する。次いでOutputから既存の結合トポロジー順を逆走査し、入力A・Bと、有効な音声ノード変調のソースを再帰的にマークする。連結した順序で実行することにより、使用しない重いSpectralMatterやModal等を計算しない。

重要：無効化したモジュレーションレーン（depth=0）は実行依存とみなさない。ノードや変調の編集により`setPatch`が呼ばれた場合には再計算される。意図的な無音パッチ、循環検出、Typed Spectral Frameの検証は変更しない。

## Resonant Exchange

各ボイス・各ノードに、共鳴周波数とColorをキーにするsin/cos係数の配列を追加。これらが不変のサンプルでは数学関数を呼ばず再利用。音声Bで制御される交換角は独立にキー比較する。係数そのものは元の`std::sin` / `std::cos`で計算し、近似やパーシャル数削減は行わない。

## 限界

- パッチ変更中に以前は死んでいたノードを接続する場合、そのノードの状態更新履歴はv1.2とは異なる可能性がある。
- ファクトリー音色の多くは全9ノードを実行するため、グラフ最適化の効果はカスタムパッチで顕著。
- Windowsビルド、VST3のホスト互換性は未確認。
