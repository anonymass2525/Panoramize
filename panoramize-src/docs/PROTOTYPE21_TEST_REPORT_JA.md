## 力学モデル

M dv/dt + C v + K x = F_ext,   dx/dt = v

Mは質量行列、Cは対称半正定値の粘性減衰行列、Kは対称半正定値の剛性行列。離散時間での陰的中点法は、線形保存系の2次形式E=1/2 v^T Mv + 1/2 x^T Kxの保存性を備える。外力および散逸時には `E(t) + ∫v^T C v dt - ∫F_ext^T v dt = E(0)` を数値チェック。

物理的な閉路はグラフを単に順番に計算せず、同一の連立方程式へ組み込んで解く。この性質は特定の線形機械系のみ保証する。音声、位相、スペクトル合成の全グラフへの一般化は未完。

## 最終完成へ残る課題

- 任意の材質を現実どおり再現する物理エンジンは存在する1つのモデルではなく、素材の構成則・温度・幾何・摩擦・接触・空気・励振法等のモデル化の集合。現在は線形等方性四面体FEMと異方性線形結合に限定。
- 動的な型付けされた**一般的な**スペクトル・位相・共鳴・機械状態の双方向交換、クロスドメインのエネルギー整合性、非線形の陰的解法、保存性/受動性の証明と条件別のフォールバックが必要。
- DSPグラフ9ノード上限と既存GUIの置換、パッチ保存互換、JUCE/VST3連携、Windows pluginvalとStudio One検証は今後必要。
- 数百自由度でも多声音リアルタイム化するには疎行列の前処理・疎解法やモード縮約、ボイス単位ではなく共有された構造のプリファクタリング、ロード制限が必要。

判定: **線形三次元状態グラフの独立した動作コアを検証済み。万能統一音響エンジンの完成は未達。**
