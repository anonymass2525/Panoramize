# Prototype 2.9: Physical Guitar Inverse — 開発仕様

## 波形から内部状態へ

1. フレーム毎RMSによる弾弦開始の粗い判定。
2. 自己相関による単音の基本周波数推定。周波数を既知値として与えるモードもある。
3. 倍音毎に0.095秒程度の窓を用い、時間的に離れた複数区間のGoertzel相当の複素射影で振幅と減衰を測る。
4. 弦の非調和性係数Bを有限候補の探索で評価。
5. 三角形状の理想化された弾弦分布と、固定の観測位置（0.78）に対し弾弦位置とスペクトル傾斜を探索する。
6. 周波数に依存した減衰係数を回帰。テイクの奏法パラメータを記録し、訓練テイクから平均的な楽器モデルを構築。
7. *学習に使わない*テイクについて、楽器共通モデルの損失を測る。テイク専用パラメータでレンダリングした場合は条件付き再構成として別ファイルを出す。

## 機能範囲

- 対象: ドライ・単音・単発の弦振動。ギター以外の弦楽器にも構造的に近い場合に適用できる可能性はあるが、実証していない。
- 出力: `.guitar29`, `.pgraph`, CSV, WAV。元音の完全模倣ではなく初期物理近似。
- GUI: Universal Patchbayのソース選択に「PHYSICAL GUITAR / INVERSE 2.9」を追加。細部パラメータはファイル経由の編集。グラフをDAW側でロードするためのJUCEコードは実装、Windowsでのビルドと実機動作は未確認。
- 弦モード発音は物理的に動機付けられた減衰正弦波の和。完全な3D有限要素モデル、フレット/運指、ノイズや胴体共鳴モデルを含まない。

## 検証条件

C++17、Linux Release GCC/Clang sanitizer。テスト用音源は同じ物理弦モデルから合成し、録音テイクの音高と奏法パラメータを変更している。正解が既知の人工音源で推定器の基礎的な機能を確かめたもの。**実ギターの録音を用いた精度評価ではない**。

報告する損失はログ倍音エネルギー・減衰・非調和性の特徴量損失であり知覚的な一致率、波形相関値、材質同定精度ではない。
