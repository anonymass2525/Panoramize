# Panoramize 2.6.0 — ネイティブ型付き状態グラフ技術検証

## 実装したもの

- 新しい `NativeState26` に、物理・スペクトル・位相・共鳴・非線形・発声の6ドメインを同じ `unified22` の方程式系としてコンパイルする仕組みを追加。
- 複数のエネルギー正規化された状態モードを、保存的結合（対称剛性行列）、散逸的結合（減衰行列）、能動入力（仕事量を計上する外部励振）で接続する。型・単位が一致しない接続を拒否する。
- 保存/散逸結合は、グラフ内の全モードを一つの行列として同時演算する。保存結合に1サンプルの人工遅延は必要ない。
- 6つのネイティブ構成サンプルを作成。`.native26` のテキスト形式でモード・接続とパラメータを外部保存できる。
- 既存の `UniversalInstrument23` のノード型へ `NativeState` を追加。JUCEグラフエディターの選択候補へ追加し、VST3用コードからMIDI演奏できる経路を作った。
- `.pgraph` はネイティブノードを使う場合のみ V26 として保存し、旧V25/V24/V23のファイルは読み込める。従来のV25だけのグラフはV25で保存を継続する。
- 製品表記を `Panoramize v2.6.0`、新規VST3 ID `Pz26` に設定。

## テストと音声

- Linux C++17 Releaseビルド成功。全DSP CTest **15/15合格**。
- 新ネイティブコア単独の AddressSanitizer + UndefinedBehaviorSanitizer + LeakSanitizer スモークテスト合格（6構造・最大16音・1024フレーム）。
- 6つの状態グラフの波形が有限・非ゼロ、型/単位違反の接続拒否、負値/無効インデックス拒否、旧V25グラフの読み込み、およびV26の往復保存を確認。
- 保存系のエネルギー収支、散逸量、能動入力の記録の専用テストを確認。今回の6サウンドの簡易有限長試験ではエネルギー残差はおおむね 1e-13 の範囲。
- 48kHz/16音同時/4096フレーム（実時間予算 85.333 ms）、新ネイティブ6構成のLinux簡易測定: **約19.6〜37.4 ms**。環境依存、JUCE/VST/DAW負荷は含まない。
- 個別WAVは48kHz/16bitステレオ、3秒。試聴MP3には再生しやすくするため loudnorm を適用。個別PCMには音量変更なし。

## 未達・注意点

**旧72ファクトリープリセットの旧DSP方程式を完全に新しい連立ソルバーへ移したわけではない。** 旧DSPは互換アダプターで継続動作。新しいネイティブ系の6ドメインは既存合成器の全機能に相当しない（複合オシレーター、サンプラー、複雑な声道物理、FEM全モデルなどは未移植）。

また、新ネイティブ系の6つのプログラムは一つの共通連立系で接続できるが、**異なるUniversal Patchbayノード同士が1つの連立方程式へ完全に融合したわけではない**。今後は複数グラフ間の共通ソルバー化と、レガシーDSP移植が必要。

- .native26はテキスト編集と独立レンダラーで読み込めるが、VST3 GUI内から任意の.native26を読み込むUIはまだ未実装。GUIは6つのネイティブテンプレート選択に対応するコードのみ。
- Windows VST3は未ビルド。JUCE GUI実行・pluginval Strictness 5・Studio Oneでの動作は未検証。
- CTest 15/15はLinux構成（VST3 OFF）。旧72音色の新旧全長PCM完全一致を今回別途測定したわけではない。
- 保存・散逸の厳密性はエネルギー正規化された物理/モードモデルの範囲。全DSP経路の厳密な受動性を保証するものではない。
- 16音実測は短いベンチマークであり大規模プロジェクトへの一般化はできない。
