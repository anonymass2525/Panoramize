# Prototype 1.0 — Formant Field 仕様

`FormantField` は音声用EQではなく、`MatterWeave`/`SpectralMatter`/`FormantField`から受け取った12成分の正値エネルギー分布を、音声ジェスチャとColorで変形しながら別の独立した位相群で再合成するノード。

音声入力Bは動的にフォルマント中心周波数を変化させる（周波数は絶対Hz）。Aは型検査されるスペクトル入力であり、A音声が0でも内部状態から再合成可能。出力スペクトル状態は後段`MatterWeave`へ渡せる。

- フォルマント: F1 300–810Hz、F2 2050–1030Hz、F3 2900–2470Hz（ColorおよびB）。
- 各部分音の振幅は正値に制限し、補間係数をサンプルレートに従って算出。
- Nyquist付近でsmoothstepフェード、固定12本の部分音。
- オーディオスレッドでは動的メモリ割当なし。有限数検証は`tests/test_panorama.cpp`。
- 音質と負荷のトレードオフ: 低音で高域フォルマントの再現性が不十分な場合がある。これはフルボーカル発声モデルではない。
