# Panoramize 3.7.0 — Generative Physical Structure 検証報告

2026-10-31 / Linux x86_64 / C++17

## 結論
研究用 **自動生成・変形可能な四面体3D構造**、生成構造を探索する **形状＋材質のInverse Synthesis**、および **弦1D・膜2D・板2D・管1Dの分布振動試作器**を実装。Panoramize 3.6の3D六弦結合物理モデルを保持。

**重要:** 旧3.6のように事前に正解メッシュを候補として渡す必要はなくなった。ただし、生成できるのは**格子由来の制約付き四面体構造**であり、実物の任意CAD形状を自動復元するわけではない。

## 新機能
- `GenerativePhysics37`: パラメータ Shape (セル数、長さ、幅、厚み、反り、テーパー) から3D四面体メッシュを生成。最大32頂点・96四面体の制約、退化四面体・不正入力の拒否、6弦ブリッジ接続点の自動割り当て。
- `ShapeInverse37`: 11種類の格子トポロジーをプログラムで生成し、学習録音だけで粗探索。高評価の候補に予算を割り振り、形状・ヤング率・ブリッジ結合・弾弦位置・一部異方性を局所探索。未使用録音は評価専用。
- `renderWave` は `String1D / Membrane2D / Plate2D / Tube1D` を個別の差分物理方程式で演算。`.wave37` で編集・保存・再レンダリング可能。
- `panoramize_render37 --demo <dir>` で形状探索の人工データと、4種類の波動音声を一括生成。
- `panoramize_render37 <recordings.txt> <output_dir> [evaluations]` でWAVから形状探索。新規コアは**オフラインCLI**。

## 既知形状の合成音による実験
- 合成録音は22,050Hz・768サンプル（約34.8ms）の3テイク。学習2件、未使用1件。
- 正解の形状は `xCells=2,yCells=1,zCells=1`、12頂点・12四面体、長さ0.20m、幅0.12m、厚さ0.08m、反り0.14、テーパー-0.09。
- **正解メッシュは初期候補ファイルとして入力していない**。生成器が11クラスを作成し、70回のレンダリング評価を行った。
- 評価誤差は波形整合＋時間窓エネルギーの相対誤差で、音響的・物理的な正解率ではない。

|順位|生成されたメッシュ|学習誤差|未使用演奏誤差|推定反り|推定テーパー|
|---|---|---:|---:|---:|---:|
|1|12頂点・12四面体|0.210911|0.228889|0.105|-0.105|
|2|18頂点・24四面体|0.240903|0.261590|0.105|-0.105|
|3|12頂点・12四面体（別分割）|0.267822|0.459563|0|-0.105|
|4|8頂点・6四面体|0.364965|0.483685|0|0|

**判定:** 正解と同じ分割数の構造を選び、幾何パラメータも初期値から変更できた。しかし、推定反り0.105（正解0.14）、テーパー-0.105（正解-0.09）などパラメータ誤差が残る。細部の形状は識別不足。各候補のブリッジ頂点位置も構造依存であり「真の形状を回復した」と断定できない。

## テストと既存機能保全
- CMake Releaseのフルビルド成功。**CTest 28/28 合格**（3.6までの26件＋新2件）。
- Clang ASan＋UBSan: `panoramize_generative37_test`, `panoramize_shape37_test` ともに合格。
- `.shape37`, `.wave37`, FEM36互換`.mesh36`, `.fem36` の保存・復元テスト。管レシピを読み込み直したWAVはバイト単位で一致。
- 旧3.6 `panoramize_render_fem36` を、同一のFEM36モデルを入力した3.7版と比較し、48kHz・約1.5秒のWAVがSHA-256完全一致。
- 既存72音色全プリセットの網羅的なPCM比較は今回未実施。
- Windows VST3のビルド、pluginval、Studio Oneでの操作・性能テストは**未実施**。

## 音声プレビュー
- `Panoramize_v3.7.0_Physical_Families.mp3` : 弦→膜→板→管、各1秒＋短い無音。各セグメントのピークを揃えた比較で、実物楽器の音色の再現を意図しない。
- `Panoramize_v3.7.0_Geometry_Inverse_AB.mp3` : 同じMIDIフレーズの人工正解3D物理モデル→推定最良モデル。両者は**共通の音量倍率**で処理しており、候補間音量差を残している。

## 非達成・今後の必要事項
- 膜・板・管の4モデルは新規に音声生成できるが、現在は**互いにも3D FEMにも双方向結合していない**。各ファミリーのInverse Synthesisも未実装。
- 2D板は簡略化された双調和項、管は1D無次元圧力／流量モデル。境界・発音機構・音響放射の本格実装はまだ。
- 3Dは小変形線形四面体FEM。実木材の完全異方性、非線形・摩擦の厳密解、任意の巨大3Dメッシュへの適用、精密なギター胴の復元は未達。
- 形状探索は最大11トポロジーの初期集合＋限られたパラメータ更新。任意メッシュの自由曲面化、トポロジー突然変異、形状の自動発明を無制限に行う最適化器ではない。
- WAV入力はドライで発音開始同期済み、MIDI音高・ベロシティが既知であることを仮定。今の検証は短い人工音のみ。実録音・長時間・複数奏法での品質は未確認。
- **3.7のDSPはまだJUCE GUIやVST3の新グラフ発音経路に未統合**。既存3.5エンジンを含む旧JUCEコードは保持している。

## 再現手順
```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure
./build/panoramize_render37 --demo demo37
./build/panoramize_render37 demo37/recordings.txt demo37/reestimate 70
./build/panoramize_render37 --wave demo37/wave_tube.wave37 tube.wav
```
