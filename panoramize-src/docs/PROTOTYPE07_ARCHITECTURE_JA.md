# PANORAMA Prototype 0.7 — Phase Ecology 音響設計

## 研究仮説

単なる発振器の加算でも、共鳴器を変調しているだけでもなく、**発振器の集団の相対位相を状態として音色を生成**できるはずである。個々の部分音は自己位相を持ち、隣接位相との相互作用で時間的な引き込み・離散化・うなりが生じる。

## 実装

各ボイス×各ノードが6成分の位相 `phi_j` を持つ。部分音の基準周波数はColorによって、ほぼ倍音的な組 (`1,1.004,2,2.008,3,3.015`) から、非整数比の組 (`1,1.088,1.617,1.743,2.431,2.597`) へ連続補間される。

位相更新（概念式）:

```
phi_j[n+1] = fract(phi_j[n] + f_j[n]/Fs)
f_j[n] = clamp(f0*r_j + K(B[n])*[
            sin(2*pi*(phi_{j-1}[n]-phi_j[n])) +
            sin(2*pi*(phi_{j+1}[n]-phi_j[n])) ] +
            D*A[n], 1 Hz, 0.44*Fs)
```

- A: 外部音声信号。位相の瞬時進行速度を変える。
- B: 外部音声信号。位相相互作用係数を変える。信号そのものを直接出力しない。
- Color: 基準スペクトルの整合度と相互作用強度を同時に変更する。
- すべての位相差は**更新前スナップショット**から計算し、ノード内の処理順序による偏りを排除する。
- 各成分はガードしたナイキスト制限内で生成する。完全な帯域制限・オーバーサンプリングは未実装。
- 波形は各部分音の `sin(2*pi*phi_j)` を重み付き加算して合成、互い違いのパンを与える。
- 従来のOutput / Global Envelope / tanh は維持。

これは物理学的に校正された素材モデルではなく、**位相結合ネットワークを用いた音響生成実験**。クルモト型の位相引力を参考にした局所位相結合であり、厳密な解析解や実在する物体の音を保証しない。

## 既存エンジンとの差

- 0.4 Harmonic：部分音の振幅・スペクトルを合成する。
- 0.5 Coupled Modes：音声Bで共鳴周波数を変化させる。
- 0.6 Resonant Exchange：共鳴状態間でエネルギーを交換する。
- **0.7 Phase Ecology：発振成分同士の相対位相が相互作用する。**

## 今後の音質研究

独立した位相エッジと同期度メーター、帯域制限処理、パーシャル生成方式の書き換え、マルチレートのプリレンダリング、静的ではない位相モーフィングとスペクトル解析。CPU負荷の大きさと音質を測定し、劣化なしでの最適化を優先する。
