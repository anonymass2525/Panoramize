# PANORAMA 1.8 — Structural Inverse Synthesis

## 1.7からの変更

1.7は9種類の定型GraphPatch×色3段階×エフェクト設定2段階の54組合せから、特徴量の距離が最小のパッチを選択した。実際の種類が同一である候補もあり、グラフの配線は探索しなかった。

1.8は、それらを初期候補（重複排除後39候補）として使い、以後は**DSPでの試聴と特徴誤差に基づく決定論的な進化探索**を行う。候補全体を最大12個のエリートとして保持し、上位候補または初期候補から新候補を変異する。乱数シードと探索予算を指定可能。

### 変異操作

- 発音器／エフェクトのノード型変更
- 既存ノード・出力ノードのA入力配線変更
- 二入力ノードのB入力配線変更
- 逐次接続ノード追加、末尾ノード削除
- 独立発音源とMixノードによる並列経路生成
- Node Level/Color と10種類のグローバルパラメーターの局所調整
- 出力取り出し位置の変更

音響グラフは9スロット（8処理＋Output）、探索するアクティブノード上限は既定6。既存の`compileGraph`と`validateModRoutes`を全候補に適用し、型違反／参照エラー／ゼロ遅延の不正な循環を排除する。実際の合成は同じ`Synth`を使い、候補構造のハッシュを用いて重複演算を減らす。探索器はオフライン専用。

### 評価関数

v1.7と同じ、3時間区間のGoertzelベース28ビン正規化スペクトル＋3区間RMS比の平方誤差。探索エリートの採用には活性ノード数あたり`1e-4`の複雑度罰則を加える。最終JSONに記録する`featureDistance`は複雑度罰則を含まない音響特徴量距離。

**重要な限界：** 対象ビンは4096フレームのうち3区間×768フレームで計測した低域中心の28ビンに限られ、全周波数帯域の聴感的再現度でも、位相・ステレオ・音量の一致でもない。発音モデルの一意な同定や全グラフ空間の網羅的最適化はできない。音高は指定が必要。単音のみ。

## インターフェース

`GraphInverseSettings{maxEvaluations, maxActiveNodes, seed}` によって探索を設定する。既存の `inferGraphFromAudio(...)` は既定設定で動作し、上位互換関数 `inferGraphFromAudioEx(...)` を追加した。返値に評価回数、変異候補数、相異なる接続構造の個数、乱数シードを追加した。

既存JUCEの `LOAD INVERSE GRAPH` ボタンは JSON `PANORAMA-GraphInverse-v1` のノード配列とパラメーターを読み込む方式を維持。1.8の新しい統計フィールドは追加メタデータで、旧インポーターで無視される。

## v1.9への課題

1.8は有界のヒューリスティック探索。絶対音量の一致、広帯域聴感損失、異なるMIDI音域への音色汎化、マルチノート入力、ゼロ遅延を含む任意回路の最適化、高度なFEM構造生成、リアルタイム逆解析は未実装。これらは実現前に評価指標・探索の安全性・CPU予算を見直す必要がある。
