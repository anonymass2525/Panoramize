# PANORAMA typeGPT 0.6.0 — Resonant Exchange 音響設計

## 開発目的

PANORAMAの目標は方式の並列配置ではなく、合成方式の内部状態を組み合わせて新しい音響現象を生成すること。
0.5の **Coupled Modes** は入力Bで共鳴周波数を揺らす設計だった。
0.6の **Resonant Exchange** は **複数の共鳴モード間で励振エネルギーを双方向にやり取り**する。

## 動作原理

- 入力 A: 2つの共鳴モード（第1、第3モード）に対する音声励振。Aがゼロで、初期状態もゼロなら出力はゼロ。
- 入力 B: 状態交換レートを音声周期で変化させる。Bの音声そのものを出力に混ぜない。
- Color: モードの基準周波数と交換レート。
- Pitch: グラフのモジュレーションレーンから、モードの基本周波数を変更可能。
- Level: 従来ノード共通の出力レベル。

4つの複素共鳴状態を持ち、2つずつペアを組む。各サンプルの独立共鳴は

```
z_j ← r_j * exp(i * omega_j) * z_j + excitation_j
```

次に各ペアを互いに回転結合する。

```
[z_0']   [ cos(theta) -sin(theta) ] [z_0]
[z_1'] = [ sin(theta)  cos(theta) ] [z_1]
```

ここで `theta=(0.012 + 0.28 * color) * (0.6 + 0.4 * B)`（Bは-1〜1に制限）。これは*複素状態のペアに対する直交変換*なので、交換処理自体は状態二乗ノルムを増大させない。共鳴過程は `0 < r_j < 1` の収縮であり、入力Aからの励振のみがエネルギーを加える。各モードで連続的に音を再計算し、サンプル毎の時変Bにも対応する。最後に出力をtanhで飽和させる。

**注意:** 実在する共鳴体の計測値や音響エネルギーの厳密なSI物理量を再現したモデルではなく、安定性を考慮した生成的なDSPモデル。位相変形、リング変調、非線形飽和によるエイリアシング低減は未完成。

## JUCEとの接続

NodeTypeを元の0〜13から**末尾の14**へ拡張し、Choiceに **Resonant Exchange** を追加。古いノード型の整数値と、既存9ノード・2レーン・グラフDAG検査・VST3識別子は維持。ただしJUCEのChoiceの正規化値が選択肢数に依存するため、**既存ホスト・オートメーションとの完全互換は未保証**。既存プロジェクトはバックアップすること。

## 将来案

0.6の研究結果を基に、明示的な状態ポートの型付け、ゼロ遅延を避けたフィードバック、モード固有の非線形性、低エイリアス化、オーバーサンプリングおよび共鳴系のGPU/CPU最適化などを検討。品質の評価と負荷の改善を分離して検証する。
