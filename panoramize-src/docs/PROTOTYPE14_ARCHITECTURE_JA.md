# Prototype 1.4 — Phase–Matter Bridge

## 目的
スペクトルのエネルギー値だけではなく、内部位相を別ノードの信号として共有する。PCMに変換してから変調する代わりに、位相速度とエネルギー状態へ直接作用させる。

## 実装
- `PhaseFrame`：サンプル単位の位相（12 cycles, [0,1)）。`SpectralFrame`：12成分のエネルギー。どちらも各Voice/graph処理内に固定長で保持、動的メモリー確保なし。
- `PhaseEcology`：6部分音の位相群を12エントリー（繰り返し）へ投影。
- `SpectralMatter` / `MatterWeave` / `FormantField` / `PhaseMatterBridge`：12成分の内部位相を公開。
- `PhaseMatterBridge`：Aは型付きスペクトル供給元、Bは型付き位相供給元。周波数変動は上限付き位相引力、スペクトル状態は位相差の相関と時間平滑で再分配。
- `compileGraph`：A/B型、DAGと接続を検証。出力が0の上流ノードも内部状態接続時は実行される。
- UI：新ノード選択肢、パラメーター保存/復元。

## 限界
独立した物理量の交換（力、変位、速度、物性パラメーター）や真の双方向フィードバック、運動方程式の時間積分は未実装。ノード間はDAGであり、位相とエネルギーの循環結合は遅延付きの将来課題。
