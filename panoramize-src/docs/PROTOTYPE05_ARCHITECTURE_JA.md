# PANORAMA typeGPT 0.5.0 — Coupled Modes 設計書

## 設計目標

従来のVA/FM/加算/モーダル等を並べるだけでなく、**音を作る要素が、別の音を作る要素の内部状態を変える**ことを、最小の新ノードで実証する。

## A/Bに異なる役割を与える

- Input A（Exciter）：共鳴モードへのエネルギー注入。Aを完全に無音にするとCoupled Modesから出る音も無くなる。
- Input B（Structural Control）：共鳴周波数を時変で移動。B自体は出力へ直接加算されない。
- Color：結合の強さと基準共鳴周波数のチューニング。
- Level：従来と同じノード出力レベル。
- 既存Mod MatrixのPitch：ノードの共鳴周波数も変更可能。

## 数理的な処理概要

4つのモードごとに直交2次元の状態ベクトル `(u,v)` を持つ。各サンプルでは変調された角周波数 `ω` と減衰率 `r` を用い、

````text
[u'] = r [ cos ω  -sin ω ] [u] + [excitation]
[v']     [ sin ω   cos ω ] [v]   [0]
````

を計算する。`0 < r < 1` であり、回転部分はノルムを増幅させないため、周波数が変化しても内部状態の指数的発散を生みにくい。`excitation` はA由来の有界信号。Bは短いローパス平滑化を通してから `2^(coupling)` に反映する。4つのモードの比率は 1 / 1.497 / 2.369 / 3.891 として、調和的な帯域と非調和的な材質を混在させる。最後に既存のノードソフトサチュレーションが適用される。

これは物理計測に基づいた共鳴モデルではなく**安定性に配慮した生成的音響モデル**。入力Bによる時間変化は音声レートだが、平滑化と出力の非線形処理によるエイリアシングは完全には排除していない。

## グラフ・GUI・互換性

既存の9ノード（8自由＋固定出力）、2変調レーン、無音グラフ救済、および音声/変調依存のDAG検証を維持。Coupled Modes型はenum値13で追加。JUCE APVTSのノード型Choiceには末尾に1選択肢を追加するため、旧値0〜11は再配置されない。既存のプラグインメーカーコード、プラグインコードとBUNDLE_IDは旧版と同一。

互換性は設計上の意図であり、Windows Studio Oneでの旧セッション保存復元テストは未実施。0.4.3は必ずバックアップする。

## Prototype 0.6以降の研究方向

- 音響グラフにオーディオ、制御、イベント、レゾナント状態等の信号型を明示する。
- ユニットディレイ経由の明示的なフィードバックを実装し、ゼロ遅延閉路を拒否する。
- エイリアシング測定、CPUプロファイル、音色探索機構、Inverse Synthesis、Sound Spaceなどを段階的に検討する。
- CPUコストより音質を先に評価するが、リアルタイム保証と安全な運用の制約は必ず明示する。
