# Panoramize v4.3.0 — テスト・性能・物理的限界

## 技術的成果
**ポート・ハミルトン型の線形・固定パラメータのC++17ソルバーを拡張**。既存の1D弦・2D膜・3D四面体FEM・0D空洞に加え、1D音響管、モーダル共鳴バンク、スペクトルを線形振動モードで近似したバンクを同時陰的中点法で解く。
- 有向PCM接続ではなく、対称の`C^T k C`/`C^T d C`で相反する境界反力を組み立てる。
- 体積変位[m³]と機械変位[m]は面積で変換。スペクトル・モードの正規化座標は任意に設定した等価変位係数で変換（物性の実測校正なし）。
- 共役量と結合の数値的エネルギー収支は検査できる。ただし、モーダル音色が実物のFEMスペクトルを再現すると証明したわけではない。
- IC(0)前処理とJacobiフォールバック。自動モードでは128 DOF未満にJacobi、以上にIC(0)を選ぶ（要機種校正）。因子分解準備中にメモリー確保あり、サンプル処理中はメモリー確保なし。

### Energy ledger（サンプル値）
- 72自由度: 初期励振に対して残差 `2.09e-16 J`、反復4（自動Jacobi）。
- 451自由度: 残差 `3.88e-19 J`、自動IC(0)、失敗サンプル0。
- 上記残差は線形・固定物性・短時間のモデル内の収支検査。全パラメータ範囲の数値的安定性、実物楽器に対する忠実性、任意非線形接触における受動性保証ではない。

## 低レイテンシ性能
Linux Release / 48kHz / 64 frames / C++ DSP単体 / 各200ブロックの中央値（同一環境内の一回の比較走行）。実時間予算は **1,333µs/ブロック**。

| モデル | Jacobi | IC(0) | 採用ポリシー |
|---|---:|---:|---|
| 72 DOF / 476 NNZ | 174µs・4反復 | 195µs・2反復 | Jacobi |
| 451 DOF / 1901 NNZ | 1,500µs・6反復 | 1,353µs・2反復 | IC(0) |

**重要:** 451 DOFの中央値はIC(0)でも実時間予算をわずかに超過。95パーセンタイルはさらに高く、ライブ演奏に安全な低レイテンシ性能とは判定できない。CPU・マルチインスタンス・オーディオホスト依存。大規模化への構造上の進歩を、実時間性能達成と混同しない。

## 音声デモ
48kHzの人工物理モデル。1) 完全結合、2) スペクトル最終リンクを外す、3) 両モードバンクを切断、4) 全リンクを外す。最終パッチは励振弦からピックアップ共鳴体への経路も失うため無音。**スペクトルモードは小さい結合係数なので現状A/B差は極めて小さい**。物理的な境界変換が可能な研究段階であり、音質改善の証明ではない。

- FEM大規模系の構造保存モデル縮約・マルチレート連成・マルチボイス・GPU/CPU並列処理。
- 周波数領域の任意スペクトルおよび既存 Native27 の非線形/発声状態との厳密な受動ポート相互運用。現状は線形スペクトルモードバンク。
- GUIでの形状・境界ポートの自由編集およびWindows Studio One本番検証。
- 受動性を保つ時変メッシュ、時変減衰、接触、摩擦の解法。

比較MP3は聞き取りやすいよう全クリップに同じ20倍のゲインを適用（クリップごとの正規化なし）。ZIP内の各個別WAVはDSPの生出力。
